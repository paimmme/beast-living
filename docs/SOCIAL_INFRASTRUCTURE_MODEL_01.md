# Social Infrastructure Model 01｜社会基础设施与支持网络拓扑

**版本：** v0.1 · Research Framework  
**状态：** 工作模型，不是已验证的统一因果理论。  
**用途：** 将物理空间、组织、日常互动、支持网络和生活机会连接起来。

## 1. 核心问题

一个人身边有没有“可以去的地方”，与他有没有可以依靠的人，之间存在怎样的中间过程？

传统研究常把空间设施、社会参与、社会支持和心理福祉分别测量。本模型把它们组织成一条可检验的过程链：

`场所/组织存在`
→ `实际可达`
→ `日常使用`
→ `重复共在与互动`
→ `关系形成/网络变化`
→ `信息、照护、情感与工具性支持`
→ `生活机会与福祉`

每一条箭头都可能受到住房、收入、时间、交通、安全、照护责任、社会规范和制度资格影响。

## 2. 四阶段：Presence → Access → Practice → Conversion

| 阶段 | 核心问题 | 候选变量 |
|---|---|---|
| Presence | 有哪些场所/组织？ | 公园、社区中心、街边商业、学校、社团、基层组织密度 |
| Access | 谁能使用？ | 距离、交通、费用、开放时间、安全、无障碍、消费门槛、被接纳感 |
| Practice | 实际发生什么？ | 出行日记、停留时间、共同参与、重复到访、共在、共同注意、交换、共同活动 |
| Conversion | 是否形成支持？ | 熟悉感、信任、互惠、弱关系、求助对象、信息流、照护与情感支持 |

重要区分：
- 地图上有设施 ≠ 现实中可进入；
- 可以进入 ≠ 有时间停留；
- 有停留 ≠ 会发生互动；
- 有互动 ≠ 一定形成稳定关系；
- 有关系 ≠ 一定能提供所需类型的支持。

## 3. 支持网络拓扑

支持不能只用一个总分描述。至少记录来源与结构：

- 家庭/亲属；
- 朋友/同伴；
- 伴侣/重要他人；
- 邻里；
- 学校/工作组织；
- 社团/社区机构/专业服务；
- 线上关系。

还需区分：
- 感知支持（perceived support）；
- 实际获得支持（received support）；
- 网络结构（network structure）；
- 支持资源的可调用性（mobilisable support）。

同一个人可能朋友很多但没有工具性支持，也可能家庭支持很强但社区联系较弱。不同支持组合不应被简单排名。

## 4. 与 Life Opportunity Budget Framework 的关系

社会基础设施是“有效机会集合”的环境与关系接口。

例如，一个青年想参加球类活动，需要：
- 场地存在；
- 费用可负担；
- 交通和时间可行；
- 身体状态允许；
- 活动对新人友好；
- 有机会重复参加；
- 关系网络允许他获得信息和邀请。

缺少任一环节，单纯提高个人动机未必能改变结果。

## 5. 研究假说

### H6｜住房空间约束与邻里社会基础设施依赖
住房越拥挤、隐私越少、越难在家接待访客，住户可能越依赖附近商业/公共场所完成停留、照护、社交和日常活动。

需要控制：收入、家庭结构、儿童照护、迁移经历、交通、工作时间和社区服务供给。

### H7｜空间配置与组织参与
控制距离后，组织节点的空间整合程度、场所混合和活动安排，可能仍能解释共同参与和成员网络差异。

候选方法：ERGM、空间句法、共同参与网络、组织名录和纵向追踪。

### H8｜支持网络构成与心理结果
不同支持来源的组合，可能比单一“支持总分”更能识别某些人群的资源与风险。

候选方法：LPA/潜在类别、社会网络分析、重复测量；同时记录感知支持与实际支持。

### H9｜代际住房支持与青年独立机会
父母住房产权、资产和制度资格，可能影响成年子女的独立住房机会；这种支持既可能缓解约束，也可能延长同住和代际依赖。

候选方法：父母—成年子女配对数据、住房 tenure、实际转移、同住时长、家庭照护、政策资格和子女住房轨迹。

### H10｜邻里凝聚、邻里满意度与福祉
邻里凝聚可能通过邻里满意度与生活满意度、幸福感和心理困扰发生联系。

候选方法：自然实验、公共住房分配机制、纵向调查、政策变化。需要区分“居住地被分配”与“邻里凝聚本身被随机分配”。

## 6. 可证伪预测

- 若只是物理距离起作用，控制距离后空间配置不应再有额外解释力；若空间配置仍有解释力，则单纯“附近”模型不足。
- 若支持总量足以解释心理结果，控制总量后支持来源组合不应再有预测价值；若仍有增量解释，支持拓扑值得保留。
- 若住房空间约束只影响家庭内部活动，不应观察到邻里商业/公共空间使用的系统变化；若出现变化，则需要把“家外栖息地”纳入住房研究。
- 若代际支持是均匀安全网，父母 tenure/资产不应显著改变支持可得性；若存在差异，家庭资源可能放大青年机会不平等。

## 7. 方法学红线

1. 不把公共设施数量当作社会联结。
2. 不把横断面 LPA 结果当作稳定人格类型。
3. 不把感知支持问卷当作真实网络规模。
4. 不把组织共同参与网络当作完整友谊网络。
5. 不把一个老龄化社区的结果推广至青年。
6. 不把家庭支持写成普遍、无代价或无条件的资源。
7. 不把预印本标成已同行评审论文。
8. 不将邻里凝聚的自然实验误写为邻里凝聚本身的随机试验。

## 8. 与现有六机制的映射

| 六机制 | 社会基础设施接口 |
|---|---|
| M1 生理预算 | 场所是否提供休息、遮阴、活动、卫生与恢复条件 |
| M2 内感受 | 安全感、疲劳、压力和身体信号影响是否使用场所 |
| M3 时间/机会 | 开放时间、通勤、排班和照护决定可用性 |
| M4 需要/满足 | 场所支持归属、玩耍、照护、意义和自主 |
| M5 地位/比较 | 群体边界、污名、被接纳感和社会评价影响参与 |
| M6 具身环境 | 空间配置、行动可供性、可达性和停留机会 |
