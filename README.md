## 我们坚持的几件事

- **双轨证据分离**：动物观察只提供视角与启发，人类结论必须回到人类临床与社科证据；两者各自评级，绝不混同。
- **不羞辱、不打卡**：残血状态下能做 5 分钟就是赢；不做“21 天逆袭挑战”，不把自我照顾变成新的 KPI。
- **看见结构性限制**：房租、工时、通勤与城市步行环境都不是靠“个人更自律”就能抹平的，该退还给系统的账绝不往自己身上揽。
- **先读正文，按需展开后台**：每篇正文都尽量保留人话与具体画面；所有研究设计、样本量、局限与 DOI 均收在文末折叠卡里，随时供核查。
