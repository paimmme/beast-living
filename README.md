# 像野兽一样生活｜BEAST LIVING

> **A field guide to being a living animal in a human world.**  
> 写给现代青年的自然主义生活指南：身体、住所、关系、休息、玩耍与自由。

现代生活教会我们怎么上班、消费、赶进度，却很少教我们怎么照顾一个会饿、会累、会想念朋友、也会想出去走走的身体。

**《像野兽一样生活》想做一份能读、能用、也能让人松一口气的生活指南。**

我们从动物和自然中寻找观察角度，再用人类生物学、心理学、社会学和公共政策研究检验能否转译。动物不是道德教科书，科学也不是用来训人的棍子。

## 怎么读

不必从第一篇读到最后，也不需要完成全部建议。挑一篇和今天有关的，试一个小动作。不适合就跳过。

每篇正文尽量先讲生活，再讲机制；研究设计、样本、反向证据和 DOI 放在文末的证据抽屉里。动物证据、人类证据和现代转译分开标注。没有动物证据时，不硬编动物故事。

## 我们坚持的几件事

- 不把动物行为直接变成人类道德规范。
- 不把个人建议包装成解决住房、工时、收入和公共服务问题的万能药。
- 不把自我照顾变成新的 KPI。
- 不羞辱内向者、残障者、慢性病患者、照护者或暂时缺少资源的人。
- 不用播放量、粉丝数和漂亮比喻替代证据。
- 允许说“还不知道”，也允许文章以后被修正。
