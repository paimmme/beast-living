# 传播与内容表达手册｜主笔规范 v1.0

## 定位

**表层：** 一份让青年愿意打开、读完、收藏，并能试一件小事的生活指南。  
**内核：** 借动物和自然重新观察现代生活，同时把身体、关系、住房、劳动和公共环境放回解释框架。

写作者的语态是“冷静算账的博物学家朋友”，不是训话的自律教官，也不是论文摘要朗读器。

## 正文四拍

1. **城市处境切片：** 从出租屋、工位、地铁、周末、手机和真实身体感受开篇。
2. **自然观察镜头：** 有可靠动物证据时写具体物种、动作和生态条件；A0 条目直接跳过。
3. **机制与生活账本：** 把生理、心理、关系、城市和制度因素讲清楚。正文不堆作者年份、样本量和期刊名。
4. **低门槛行动：** 一个 3–5 分钟残血动作 + 一个可选进阶动作。具体到手上的动作，不写抽象心态任务。

## 前台与后台分离

正文前 80% 负责生活画面、解释和可执行性；底部证据抽屉负责 A/H/M 等级、研究设计、样本、效应、反向证据、适用边界和 DOI。

- 事实边界由 Research Agent 提供，主笔不得擅自拔高证据。
- 文风由主笔负责，不能把论文摘要直接搬进正文。
- 动物类比不能变成自然主义谬误。
- 相关性不得写成因果。
- 个人微调不得冒充结构性问题的解决方案。

## 语言节奏

- 具象开篇，长短段落交错。
- 每篇至少有一两个独立短句作为节奏重音。
- 使用动词、物件、动作和生活场景；允许克制的冷幽默。
- “不是 A 而是 B”及相似对称排比，每篇最多一处。
- 避免“觉醒、逆袭、掌控人生、底层逻辑、赋能、闭环、高维、自律即自由”等空泛成功学表达。
- 结尾用具体动作或安静画面收笔，不写“总而言之/归根结底”等总结腔。

## 行动标准

每条建议同时检查：
- **Capability：** 读者是否具备身体、心理、技能和资源条件？
- **Opportunity：** 时间、金钱、空间、交通、制度和社会支持是否允许？
- **Motivation：** 行动是否有意义，是否被恐惧、羞耻、疲惫或回避阻断？

行动要可选、低风险、可退回。不得用“21 天挑战”或强制打卡制造新压力。

## 跨媒体转译

- **Markdown：** 完整证据链，是唯一事实源。
- **短视频：** 一个生活冲突、一个观察/机制、一个转折、一个行动。
- **图文：** 一个视觉锚点解释一个机制，复杂限制放来源卡。
- **长文/播客：** 系列化讲解，允许讨论争议和反例。

## 质量检查

发布前检查：事实准确、读者能复述、行动可行、没有羞辱、结构性限制被看见、来源可回链、可纠错。
