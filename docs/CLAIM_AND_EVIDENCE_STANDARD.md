# 主张与证据标准

## 为什么不用单一“证据等级”

本项目同时讨论动物行为、人类健康和编辑类比。一个动物学研究很可靠，并不意味着它能证明某种人类生活建议。因此每条内容采用三个独立标签：动物证据 `A`、人类证据 `H`、转译强度 `M`。三者不合并成一个总分。

## 动物证据（A）

- `A1`：系统综述、Meta-analysis，或多个独立研究形成的较一致证据。
- `A2`：同行评审的原始研究；结论必须限定到对应物种、样本和环境。
- `A3`：可信教材/专业机构的二手概述，或有记录但尚未系统验证的观察。
- `A0`：尚无可核验的动物学来源，或该条不需要动物学类比。

## 人类证据（H）

- `H1`：权威公共卫生/临床指南、系统综述或 Meta-analysis。仍需检查其确定性和适用范围。
- `H2`：多项同行评审研究、较强实验/纵向证据，或成熟理论综述。
- `H3`：单项研究、小样本、横断面、定性或观察性证据；适合提出问题，不宜做强因果结论。
- `H0`：没有直接的人类结果证据，或目前只是一种编辑建议/类比。

## 转译强度（M）

- `M1`：动物观察与人类实践之间有明确、有限的机制联系；仍不能视为因果证明。
- `M2`：启发式类比，主要用于重新观察问题；人类行动需要独立证据支持。
- `M3`：文学/视觉隐喻，不承担事实论证功能。
- `M0`：无动物类比。

## 编辑判断（E）

`E` 表示作者的价值判断或实践建议，不是科学证据。例如“不要把每一分钟都变成生产力”属于项目立场，不应伪装成实验结论。

## 推荐标注格式

```text
Animal: A1 | Human: H3 | Translation: M2 | Editorial: E
```

## 措辞规范

| 不建议 | 建议写法 |
|---|---|
| 动物都需要领地 | 某些物种会在特定生态条件下防御特定资源或空间 |
| 整洁的房间能降低焦虑 | 一项小样本观察研究发现，受访者对家居环境的描述与部分压力相关指标存在关联；不能据此证明整理房间能治疗焦虑 |
| 孤独会让人早死 | Meta-analysis 发现社会关系与生存率相关；研究并不能把所有关联都解释为因果 |
| 动物玩耍能让大脑更聪明 | 动物玩耍的功能仍在研究；部分理论提出练习/发展等假说，不能泛化成确定的人类收益 |
| 亲近自然治愈心理问题 | 自然暴露研究报告了一些认知/情绪方面的积极结果，但效应大小、研究人群和异质性需要说明；不能替代治疗 |
| 追随本能就能活得自由 | 识别需求是重要能力，但冲动、习惯和被商业环境塑造的欲望也需要辨别 |

## 高风险内容

涉及疾病、药物、营养补充剂、饮食限制、性健康、创伤、精神健康、家庭暴力、财务/法律安全等主题时，必须使用相应专业指南，并由专业人士复核。没有专业来源时不写处方性建议。
