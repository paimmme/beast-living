# BEAST LIVING｜内容转译模型 01

**版本：** 0.1 · Creator Research 01 的项目化转译  
**用途：** 将青年生活问题、动物观察、人类研究、行为模型和传播叙事组合成可复用的 Markdown 条目与媒体内容。

## 1. 核心流程：八步内容链

### Step 1 — 真实生活问题
从青年生活中选一个具体问题，而不是先找动物故事再强行配上人类建议。

示例：回到出租屋仍然无法放松；想运动却无法开始；朋友很多却没有可以求助的人；休息时仍然内疚；工作和社交平台占据全部注意力。

### Step 2 — 戏剧性问题 / 认知预测
借鉴 Veritasium 和科学视频叙事研究：用一个清楚的问题让读者产生认知参与。

示例：
- 为什么有些动物的领地越大，维护成本反而越高？
- 为什么一个人明明知道运动有益，却还是无法开始？
- 为什么并不是所有社交关系都能缓解压力？

可以邀请读者先做预测，但不能制造虚假二分或刻意误导。

### Step 3 — 具体观察
借鉴无穷小亮和行为生态学的观察方式。必须写清物种、行为、生态背景、研究设计、研究者如何获得结论，以及哪些解释仍有争议。

如果没有可靠动物证据，可以直接从人类研究开始，不强行加动物故事。

### Step 4 — 机制解释
借鉴 Sapolsky 的多时间尺度思路和 COM-B：
- 身体层：生理、睡眠、活动、压力调节；
- 个体心理层：能力、信念、动机、情绪；
- 人际层：支持、关系、规范、冲突；
- 物理环境层：住房、街道、绿地、噪声、光照；
- 制度与数字层：工时、收入、公共服务、平台设计。

不要只用一个心理标签解释复杂行为。

### Step 5 — 证据与反证
借鉴 Kurzgesagt、混知和 Huberman Lab 的研究转译方法：
- 每一个关键事实都能回到原始来源；
- 动物证据与人类证据分开；
- 相关性与因果性分开；
- 研究设计、样本和局限必须记录；
- 主动寻找反例、替代解释和不支持当前观点的证据；
- 专家意见不能替代原始研究，AI 摘要不能替代原文。

### Step 6 — 生活转译与可选行动
采用 COM-B 检查行动是否可行：

| 维度 | 要问的问题 |
|---|---|
| Capability 能力 | 读者是否有知识、技能、体力和资源？ |
| Opportunity 机会 | 时间、金钱、空间、交通、制度和社会支持是否允许？ |
| Motivation 动机 | 行动是否有意义？是否受到恐惧、羞耻、疲惫或回避影响？ |

再用自我决定理论检查行动是否支持自主、胜任和关系。行动要低风险、低门槛、可选，不承诺治疗效果。

### Step 7 — 限制与边界
每条内容至少回答：
- 哪些人群可能不适用？
- 哪些条件会让行动不可行？
- 是否存在潜在伤害或羞耻感？
- 何时需要专业医疗、心理、法律或社会服务？
- 是否把制度问题错误地转化为个人问题？

### Step 8 — 复核、发布与反馈
- 独立审稿人对照原始来源核查事实；
- 读者反馈用于发现表达不清、行动不可行或被误解之处；
- 发现证据更新时将条目标记为 RECHECK；
- 更正记录必须保留，不以删除旧内容掩盖错误。

## 2. 一条内容的标准结构

1. 标题：具体生活问题，避免抽象口号。
2. 开头：一个真实场景或明确问题。
3. 动物观察：仅在有可靠依据时使用。
4. 人类机制：解释身体、心理、关系或环境因素。
5. 研究证据：关键来源、设计、样本、结果和限制。
6. 生活转译：一到三个可选行动。
7. 不要误解为：澄清不能推出什么。
8. 适用边界：说明结构性约束和专业求助条件。
9. 来源：DOI、PMID、官方指南、来源卡。

## 3. 不同媒体形式的转译

### Markdown / 知识条目
完整呈现证据链；保留方法、限制和来源；作为唯一事实源；允许读者按章节和主张检索。

### 短视频 / 动画
只解决一个问题；先建立问题，再给出一个关键转折；一条视频不承载整篇综述；动画隐喻必须与原机制一致；结尾给出洞见，不要求读者打卡。

### 图文 / 漫画
用一个核心视觉锚点解释机制；图中标明关键条件和不确定性；复杂例外和引用放入来源卡或延伸阅读；不把视觉简化变成事实简化。

### 长文 / 播客
围绕一个主题形成系列；先解释基础概念，再讨论机制、争议和行动；后续内容回访旧主题，建立知识连接；对专家、读者和不同立场保留提问空间。

## 4. 项目专属传播质量指标

| 指标 | 检查方式 |
|---|---|
| 事实准确性 | 关键主张是否能回链原始来源 |
| 理解程度 | 读者能否用自己的话复述核心机制 |
| 记忆锚点 | 是否留下正确、可迁移的认知模型 |
| 行动可行性 | 行动是否低门槛、可选择、符合现实条件 |
| 非羞耻性 | 是否避免把结构性困境归咎于个人 |
| 长期价值 | 三年后是否仍然有解释或查阅价值 |
| 纠错能力 | 是否有来源更新、反馈和修订记录 |

## 5. 创作红线

- 不把动物行为直接变成人类道德规范。
- 不把创作者的个人理论框架冒充同行评审理论。
- 不把流行度、点赞或粉丝规模当作科学可信度。
- 不为了情绪唤起夸大风险。
- 不把健康实践写成每个人必须完成的清单。
- 不以“21 天养成习惯”等缺乏依据的口号制造压力。
- 不把读者的住房、收入、残障、照护和工作限制归咎于个人不够自律。

## 6. 最终原则

**让内容有故事，让解释有模型，让事实有来源，让行动有选择，让读者保有自由。**
