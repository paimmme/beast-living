# 原则与边界

## 1. 自然不是道德法典

动物行为描述“发生了什么”，不自动回答人类“应该怎么做”。自然界存在合作、照料、竞争、欺骗、寄生和暴力。项目不从“自然存在”推出“道德上正确”。

## 2. 不存在统一的野兽

狼、海獭、乌鸦、象、灵长类、鸟类和昆虫拥有不同生态位。领地、群居、玩耍、休息等行为的定义和功能都可能不同。所有事实主张都必须注明物种和情境。

## 3. 不浪漫化原始生活

自然环境可能包含饥饿、疾病、寄生、捕食和高死亡风险。项目不是鼓励放弃现代医疗、住房、法律、社会保障或技术。

## 4. 不制造新的自律崇拜

- 不要求读者完成全部建议。
- 不把健康、社交、运动、休息变成新的打卡竞赛。
- 不用羞耻、恐惧和道德优越感推动行动。
- 允许不同节奏、能力、资源与人生阶段。

## 5. 不走 Alpha / 霸权叙事

“野兽”不是男性支配、攻击性、肌肉崇拜、排斥弱者或情绪压抑的代名词。项目强调身体感、互惠、边界、恢复和自主，不鼓吹支配他人。

## 6. 不把结构性问题全部个人化

青年缺乏休息、住房空间、社交时间和自然环境，可能与工资、工时、住房制度、城市规划、照护责任和公共设施有关。不能把结构性约束都归咎于个人不够自律。

## 7. 不把“听从本能”当万能建议

人的欲望会受到学习、文化、压力、营销、成瘾机制和社会环境影响。识别需求不等于满足每个冲动。

## 8. 安全与专业边界

内容不能替代医生、心理治疗师、营养师、律师或其他专业人员的判断。遇到持续症状、危机或安全风险时，应提供求助方向，而不是用动物隐喻替代专业支持。
