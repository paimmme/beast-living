# Variable Dictionary 01｜青年生活研究变量字典

**用途：** 为研究选题、证据卡、未来数据分析和模型可视化提供共同变量语言。  
**状态：** v0.1 工作字典；不是现成量表，不提供个人诊断阈值。

## 1. 结构性暴露与资源

| 变量 | 操作化候选 | 主要层级 | 注意事项 |
|---|---|---|---|
| Housing affordability | 房租/家庭可支配收入；住房价格收入比；住房支出负担 | 家庭/制度 | 自有住房、租房和家庭支持应分开 |
| Housing security | 租约稳定、被迫搬迁经历、驱逐威胁、续租不确定 | 家庭/制度 | 不等于住房可负担性 |
| Housing quality | 拥挤、通风、噪声、温度、维修、隐私 | 物理栖息地 | 主观满意度与客观质量分开 |
| Employment stability | 合同类型、失业/欠薪、排班可预测性 | 制度/工作组织 | 不要只用“是否就业” |
| Paid work time | 有酬工时、加班、非工作时段任务 | 个体/组织 | 需说明统计口径 |
| Unpaid work/care | 家务、照护、无酬实习、家庭支持 | 家庭/性别分工 | 时间与情绪/责任负荷可能不同 |
| Commute burden | 单程时间、费用、可靠性、拥挤、可预测性 | 城市/个体 | 区分通勤时间和通勤压力 |
| Schedule control | 自主安排工作/休息时间的程度 | 组织/个体 | 不等于总工时 |
| Disposable resources | 可支配现金、储蓄缓冲、家庭转移、公共福利 | 家庭/制度 | 现金流、资产和福利权利分开 |

## 2. 时间利用与时间贫困

| 变量 | 操作化候选 | 来源/测量 | 注意事项 |
|---|---|---|---|
| Paid labor time | 每日/每周有酬劳动时间 | 时间日记、劳动调查 | 参与者平均与总体平均分开 |
| Unpaid labor time | 家务、照护、无酬工作 | 时间日记 | 性别、家庭结构和年龄分层 |
| Commute time | 日均交通时间、通勤单程时长 | 时间日记、通勤调查 | 交通时间不等于全部通勤负担 |
| Sleep/rest time | 睡眠、午休、静息 | 时间日记、睡眠日记/设备 | 时间长度不等于质量 |
| Leisure time | 文化娱乐、运动、休闲兴趣 | 时间日记 | 不要把所有自由时间视为恢复性休闲 |
| Social interaction time | 社交交谈、聚会、电话/信息等 | 时间日记 | 线上线下、工作/非工作性质需区分 |
| Internet use | 各类活动中互联网使用 | 时间日记/设备 | 可能与其他活动重叠，不能简单相加 |
| Time poverty | 可支配时间低于某阈值，或时间需求超过可用时间 | 需明确定义 | 无单一全球统一阈值 |
| Time control | 对时间安排、节奏和临时变动的控制感 | 问卷/访谈 | 主观控制感与客观时间分开 |
| Work-hour mismatch | 实际工时与偏好工时的差距 | 劳动力调查 | 工时不足和过度要分别编码 |

## 3. 身体与生理预算

| 变量 | 操作化候选 | 常见测量 | 注意事项 |
|---|---|---|---|
| TEE | 总日能量消耗 | 双标水 | 不宜由手环单独替代 |
| REE/RMR | 静息能量消耗 | 间接测热 | 需控制测量条件 |
| AEE/PAEE | 活动能耗 | 传感器/差分估计 | 差分估计存在误差放大问题 |
| Physical activity | 活动量、强度、时长、类型 | 加速度计、问卷、日志 | 职业活动与休闲活动分开 |
| Sedentary behavior | 清醒时低能耗坐/躺时间 | 加速度计/自报 | 不等于缺乏运动 |
| Sleep duration | 睡眠时长 | 睡眠日记、设备、PSG | 设备估计与临床测量不同 |
| Sleep quality | 睡眠连续性、主观恢复感 | PSQI、日记等 | 量表不是诊断 |
| Fatigue | 主观疲劳、身体疲劳、认知疲劳 | 多维问卷/EMA | 不能用单一“能量分数”替代 |
| Stress exposure | 压力事件、持续性暴露、工作/住房压力 | 事件清单、访谈 | 暴露与生理反应分开 |
| Recovery opportunity | 工作后无干扰时间、睡眠机会、休息自主性 | 日记/问卷 | 不是简单等于“休息时长” |

## 4. 内感受与身体状态解释

| 维度 | 研究对象 | 候选测量 | 注意事项 |
|---|---|---|---|
| Interoceptive accuracy | 特定任务中内部信号检测表现 | 心跳辨别、呼吸阻断等任务 | 不能用单一心跳计数代表全身能力 |
| Interoceptive sensibility | 自我报告的身体感受/注意倾向 | MAIA 等 | 主观报告不等于客观准确 |
| Interoceptive awareness/insight | 信心与客观表现的元认知对应 | 信心评分与任务表现 | 需任务和统计定义 |
| Interoceptive attention | 注意身体信号的方式与灵活性 | EMA、问卷、任务 | 适应性与不适应性注意要区分 |
| Interpretation | 如何解释身体信号 | 访谈/量表/实验操纵 | 疾病焦虑与合理求医要区分 |
| Regulation | 如何根据身体状态调整行为 | 行为任务、日记 | 不等于“自我控制力” |
| Propensity | 日常情境中使用内部信号的倾向 | EMA/多次测量 | 比单次实验室表现更接近现实使用 |

## 5. 关系、社会比较与地位

| 变量 | 操作化候选 | 主要理论 | 注意事项 |
|---|---|---|---|
| Social network structure | 关系数量、密度、频率、角色分布 | 社会网络分析 | 数量不等于质量 |
| Support function | 情感、信息、工具性支持 | 社会支持研究 | 支持类型与需求匹配 |
| Relationship quality | 安全、信任、冲突、互惠 | 关系研究 | 低质量关系可能有害 |
| Loneliness | 主观联结缺口 | UCLA 等量表 | 不等于社会隔离 |
| Social isolation | 客观互动/网络不足 | 网络指标/独居等 | 独居不等于孤独 |
| Co-presence | 与他人共享空间 | 公共空间观察 | 不必发生交谈 |
| Co-attention | 共同注意同一对象/事件 | 观察/访谈 | 可能是短暂互动 |
| Co-exchange | 信息或物品交换 | 观察/事件编码 | 不等于亲密关系 |
| Co-action | 共同活动 | 活动日志/观察 | 可能促进重复接触 |
| Assembly | 集会/公共聚集 | 观察/空间分析 | 需考虑安全与政治可及性 |
| Social comparison | 上行/下行比较、目标、频率 | 问卷/EMA/实验 | 比较方向、目标和解释要区分 |
| Status | 尊重、钦佩、自愿服从 | 地位动机研究 | 与权力、财富、归属区分 |
| Dominance | 威慑/强制影响力路径 | 支配—声望模型 | 不等同于所有领导力 |
| Prestige | 技能/贡献带来的自愿尊重 | 支配—声望模型 | 声望并非天然道德善 |

## 6. 物理空间与行动可供性

| 变量 | 操作化候选 | 注意事项 |
|---|---|---|
| Accessibility | 步行/公共交通时间、开放时间、费用 | 地图距离不等于实际可达 |
| Safety perception | 日夜安全感、交通安全、骚扰风险 | 主观感知与客观犯罪/交通数据分开 |
| Universal design | 无障碍路径、座椅、卫生间、坡道 | 对残障、老年、照护者特别重要 |
| Non-commercial stay | 不消费是否可停留、是否被驱赶 | 识别半公共空间的消费门槛 |
| Mixed land use | 居住、商业、服务和公共设施混合 | 与步行/活动相关但非自动因果 |
| Seating and amenities | 座椅、遮阴、饮水、厕所、照明 | 设施需结合维护和管理 |
| Place attachment | 地方依恋、熟悉感、归属 | 与居住年限、迁移经历有关 |
| Affordance | 特定身体在具体环境中的行动可能性 | 必须说明主体、环境和行动 |

## 7. 心理与生活结果

- 主观幸福感/生活满意度
- 抑郁和焦虑症状（仅作为研究结果变量，不用于内容自诊断）
- 自主、胜任、关系需要满足
- 社会凝聚与邻里归属
- 生活自主性与选择空间
- 体力活动、睡眠与功能状态
- 疲劳与恢复体验
- 工作意义与工作—生活边界

## 8. 重要混杂/分层变量

年龄、性别/性别角色、残障、慢性病、教育、收入、就业状态、家庭结构、照护责任、住房产权/租赁、城市/农村、迁移经历、族群/少数身份、居住年限、公共空间可及性、平台使用方式。

## 9. 最小分析规范

1. 先写清分析单位：个人、家庭、社区、城市或制度。
2. 先写清时间窗口：一天、一周、数月、数年。
3. 不把横断面相关解释为因果。
4. 不把总体均值写成青年均值。
5. 不把参与者平均写成全体平均。
6. 不把主观自评当作客观测量。
7. 不把可穿戴设备的估算当作临床或实验室测量。
8. 不把结构性条件塞进“个人自律”变量。
