## 0. 审计原则

02C 中的“原创理论卷”是跨库漫游产生的创意综合材料。它们的价值在于提出联想、组织问题和生成选题，不自动构成经过同行评审的科学理论。

本审计把“理论”拆成五种不同对象：

1. **经验性构念/理论：** 有明确变量、可测量定义、可检验预测和相关实证研究。
2. **机制框架：** 用于组织多个变量和过程，部分路径有证据，但整套框架未必经过整体验证。
3. **分析启发式：** 帮助提出问题或做决策，不声称描述普遍自然规律。
4. **规范性/哲学主张：** 讨论值得怎样生活、什么算好，不以实验结果单独判定。
5. **类比/创作者原创命名：** 把两个领域的结构相似性转成记忆工具；若无操作化与独立验证，只能标为 metaphor / hypothesis。

### 状态标签

- **KEEP-AS-EMPIRICAL：** 可保留为有限经验性主张，仍需写明边界。
- **KEEP-AS-HEURISTIC：** 可作为分析工具，不得称为科学定律。
- **KEEP-AS-METAPHOR：** 可作叙事隐喻，正文必须明确是类比。
- **REBUILD-AS-HYPOTHESIS：** 有研究价值，但需定义变量、提出可证伪预测。
- **REJECT-AS-SCIENCE：** 存在明显的类别错误、错误物理/数学转译或无证据的强因果主张。

### 1.1 本轮最值得保留的三个创意母题

**A. 依赖链与固定成本反馈（Theory 005）**

可改写成可检验问题：

- 消费承诺、债务偿付、住房成本与工作时长之间是否形成正反馈？
- 固定支出上升是否降低个体拒绝加班/转换工作的能力？
- 收入不稳定、家庭支持和社会保障如何调节该关系？

可连接：家庭金融、劳动经济学、消费社会学、时间贫困研究。

**B. 赛季制与技能折旧（Theory 004）**

可改写成：

- 技能的市场回报如何随技术变化、行业周期和组织制度而折旧？
- 哪些技能可跨行业迁移，哪些高度依赖当前平台/工具？
- “学历贬值”与“技能折旧”是否被混为同一过程？

可连接：技能偏向型技术变迁、职业流动、教育回报、任务自动化研究。

**C. 圆桌挤出与身体状态 UI（Theory 010）**

可拆成两个完全独立的假说：

- **时间/注意挤出假说：** 高频、紧急、可见的义务是否挤压低频、长期、非紧急的活动？
- **主观状态校准假说：** 人的主观疲劳判断是否会在长期睡眠不足/工作负荷下偏离客观表现？

二者需要不同测量，不能用受限能耗模型把它们粘在一起。

## 2. 30 个心智模型：重新分类，而不是把它们统称为科学理论

来源文档的 30 个模型可按功能分为：

### A. 经验性行为/经济学构念（需限定情境）

- 损失厌恶（Loss aversion）
- 参照点（Reference points）
- 框架效应（Framing）
- 享乐适应（Hedonic adaptation）
- 机会成本（Opportunity cost）
- 沉没成本（Sunk cost）
- 激励（Incentives）
- 社会证明（Social proof）
- 位置性商品/地位消费（Positional goods / status consumption）
- 边际效用递减（Diminishing returns）

**使用规则：** 这些概念在相应学科中有研究传统，但效应强度、适用任务、人群和制度情境会变化。不能将其简化成“人性永远如此”的定律。

### B. 系统动力学/组织分析工具

- 反馈回路（Feedback loops）
- 杠杆点（Leverage points）
- 成功者愈成功（Success to the successful）
- 信息流结构（Information flows）
- 古德哈特定律（Goodhart's law）
- 红皇后效应（Red Queen effect）

**使用规则：** 先画出系统边界、存量、流量、反馈和延迟；Goodhart 不是“所有指标一旦被测量就失效”，而是当指标被用作控制目标时，原统计关系可能被破坏。社会指标场景还应参考 Campbell's law。

### C. 决策启发式与认识论工具

- 第一性原理（First principles）
- 逆向思考（Inversion）
- 二阶效应（Second-order effects）
- 地图不是疆域（Map is not the territory）
- 能力圈（Circle of competence）
- 手里拿着锤子（Man with a hammer）
- 快而俭的启发式（Fast and frugal heuristics）
- 概率思维/下注思维（Thinking in bets）
- 思想实验（Thought experiment）

**使用规则：** 它们是帮助思考的工具，不是自然科学理论。尤其第一性原理不能把未经验证的假设伪装成“公理”。

### D. 风险与规范性策略

- 经由否定（Via negativa）
- 安全边际（Margin of safety）
- 反脆弱（Antifragility）

**使用规则：** Taleb 的反脆弱是具有影响力的概念框架，但不同领域的“从波动中受益”需要单独定义和测量；Via negativa 是策略/哲学启发，不是普遍最优原则。

### E. 社会地位与竞争模型

- 地位游戏与位置商品（Status games / positional goods）
- 红皇后效应（也可作为进化隐喻）
- 享乐适应（也可归入行为心理学）

**使用规则：** 地位、权力、财富、声望、归属、受欢迎程度并非同一变量。不要用“地位游戏”解释所有动机。

## 3. “从动物到社会人”欲望库的基础假设审计

原资料库提出：生物底座（能量、体温、睡眠、安全）是“不可取消”的需要；社会化后叠加的欲望通过代价、依赖和社会规训形成枷锁。

可保留的部分：
- 区分需要（need）与满足方式（satisfier）是有用的分析方法。
- 将欲望成本拆成时间、金钱、注意力、依赖、照护和制度条件，有助于看见机会成本。
- 位置性商品、地位比较、享乐适应、模仿欲望可用于提出不同机制假说。
- “低欲望”必须区分自愿节制、资源不足导致的被迫收缩、暂时的抗议姿态。

需要修正的部分：
- 人类的生物需要不止能量、体温、睡眠和安全；关系、依恋、照护、性、生殖、疼痛回避、免疫、发展和自主行为等也涉及生物/心理过程。
- 人类是社会性、文化性和制度性动物；不能把“动物”定义成纯生理底座，再把所有关系、意义和身份都视为后天枷锁。
- “吃饱、暖和就有天然够了”是过度简化。食欲、饱腹、温度舒适和安全感都受学习、环境、发育、病理状态和社会条件影响。
- 伊壁鸠鲁欲望分类是古典哲学规范框架，不是现代生理学的欲望分类实验。
- Max-Neef 的需要/满足方式框架是规范性发展理论，不应包装成唯一被实验验证的普遍需要清单。
- “负担评分 0–3”若无量表开发、信效度和跨人群测量，只能作为用户自我反思工具，不能用来排名或诊断。

## 4. 主笔与研究 Agent 的接口

研究 Agent 提供：
- 原始主张及其出处；
- 变量定义和操作化；
- 研究设计、样本、效应及局限；
- 反向证据；
- 可以保留的有限表述；
- 不得使用的强表述；
- 可转译的问题，而非读者版句子。

主笔 Agent 可以：
- 自行选择标题、故事、动物观察和表达结构；
- 不必采用研究 Agent 的模型命名；
- 可以不用动物类比；
- 不得把 KEEP-AS-METAPHOR 或 KEEP-AS-HEURISTIC 改写成已验证的科学定律。
