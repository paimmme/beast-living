# 传播与内容表达手册

## 传播定位

**表层：** 一份有趣、好读、能马上用的生活指南。  
**内核：** 对过度优化、社会比较和脱离身体的现代生活方式进行温和反思。

不要把项目做成“骂醒年轻人”的账号。读者不是需要被训斥的人，而是需要获得理解、信息和可选行动的人。

## 单条内容的叙事结构

1. **生活钩子**：从一个真实、具体的青年生活场景开始。例：“你把出租屋当成了一个临时睡觉的地方吗？”
2. **动物镜头**：讲一个具体物种的行为，明确物种和情境。
3. **科学解释**：说明研究真正发现了什么、没有发现什么。
4. **人类映射**：指出它能提醒我们观察的生活问题；清楚标注类比边界。
5. **一个小行动**：读者可以尝试，但不必完成。
6. **边界与来源**：说明不适用情境，给出可点击的原始来源。

## 内容格式

- **短卡片（4–7 张）**：一张提出问题，一张动物观察，一张人类证据，一张行动，一张边界/来源。
- **短视频（45–90 秒）**：一个生活冲突 + 一个动物行为 + 一个证据结论 + 一个低门槛行动。不要把论文数字塞满画面。
- **长图文（800–1800 字）**：适合有争议、需要讲清楚研究限制的主题。
- **研究札记**：完整呈现来源、研究设计、争议和不确定性，供深度读者使用。
- **交互小工具**：帮助读者从“我现在最困扰什么”进入对应条目，不做心理诊断或人格测试。

## 语气

- 直接、温和、略带幽默，不居高临下。
- 用具体动词，不用“觉醒、强大、掌控命运”等空泛词。
- 允许承认“目前不知道”“证据不够”。
- 避免恐吓、羞辱、贩卖焦虑、制造男女对立和反智表达。

## 视觉方向（初版）

**方向名：城市自然观察手册 / Urban Field Guide**

- 视觉关键词：自然观察笔记、野外图鉴、城市生活切片、科学插图、手绘标注。
- 主要元素：动物剪影/足迹/栖息地图/行为序列图；同时呈现出租屋、公交、办公桌、公园、街道等现代青年场景。
- 色彩建议：纸张米白、墨黑、苔藓绿、土褐、少量警示橙；作为初版方向，需做可读性和品牌测试。
- 避免：迷彩、军武、獠牙、肌肉硬照、Alpha 男性符号、伪科学能量图。
- 图像来源：优先自制插画、CC 授权素材或明确可商用授权的图片；野生动物照片必须标注来源和许可。

## 渠道适配

### 小红书 / Instagram Carousel

- 首图用生活问题，不用宏大口号。
- 每页只承载一个观点。
- 最后一页保留来源链接/二维码和“你可以只试一条”。

### 抖音 / Bilibili

- 开头 2–3 秒用一个生活场景。
- 视觉上先讲故事，再展示证据；研究数字用字幕/来源卡呈现。
- 不用“科学证明你必须……”等绝对化标题。

### 长文 / Newsletter

- 用一个真实场景引出问题。
- 让研究承担解释，不让研究沦为装饰。
- 对争议和反例保留篇幅。

### GitHub / 网站

- GitHub 是知识源文件和变更记录，不是普通读者唯一入口。
- 网站承担搜索、章节导航、证据标签和来源回链。
- 每个条目有稳定 ID，方便引用、翻译和后续 Agent 检索。

## 传播效果评估

不要只看播放量。至少观察：收藏率、分享率、来源点击、读者是否正确理解证据边界、评论中的误解类型、读者是否反馈行动可行。避免以争议、羞辱和恐惧作为增长策略。
